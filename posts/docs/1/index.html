ทำไมถึงเขียน Guide อันนี้?

เพื่อขอโทษสังคมจากใจจริง ที่พูดว่า Pipe operation (dplyr) ยากกว่า data.type ทั้งที่ dplyr นั้น ง่าย สำหรับคนเริ่มหัดเขียน และโครงสร้างไม่ซับซ้อน

ลองมาดูตัวอย่างกันดีกว่า

# option 1: แบบ data.table

library(data.table)
dt <- as.data.table(diabetes_data)
result_01 <- dt[age >= 50, .(n_patients = .N,mean_hba1c = round(mean(hba1c), 2)), by = gender][order(gender)]
print(result_01)

# Cr. Aj. Chanon
# option 2: แบบ Pipe (dplyr)

library(dplyr)

result_02 <- diabetes_data %>%
  filter(age >= 50) %>%
  group_by(gender) %>%
  summarise(
    n_patients = n(),
    mean_hba1c = round(mean(hba1c), 2),
    .groups = "drop"
  ) %>%
  arrange(gender)

print(result_02)

# Cr. Aj. Chanon

คือเราสามารถเห็นได้ชัดเจนเลยว่า dplyr มันเรียงเป็นตอน ๆ และดูได้ง่ายกว่า data.table เยอะ เพราะเขียนเรียงกันมาเลย แต่การเขียน data.table นั้น ต้องมองภาพเป็นตารางก่อน แล้วจึงเขียนออกมา

แต่ในเมื่อเลือก data.table แล้ว เราก็มาลุยกันดีกว่า เพราะจริง ๆ มันก็ไม่ได้ยากอย่างที่คิดเสมอไป เนื้อหาที่เขียนอาจเหมือน หรือไม่เหมือนใน workshop ค่อยว่ากัน ถือว่า อ่านปูพื้นฐาน

ทำความรู้จักกับโปรแกรมสถิติ R

R ก็เป็น open source ที่ใช้สำหรับการประมวลผล และวิเคราะห์ข้อมูลสถิติ ซึ่งตัวภาษา R นั้นใช้ง่ายมาก ๆ ไม่ได้โกหกอะไรเลย ลองดูการคิดเลขปกติดู

1+1 # บวก
[1] 2
5-7 # ลบ
[1] -2
8*9 # คูณ
[1] 72
9/3 # หาร
[1] 3

เห็นไหมว่าภาษา R ก็ไม่ได้ยากอย่างที่คิด ฉะนั้น ก่อนเข้าเนื้อหา data.type เราต้องใช้ภาษา R แบบเบื้องต้นเป็นเสียก่อน

การดำเนินการและฟังก์ชันทางคณิตศาสตร์

นอกจากการบวก, ลบ, คูณ และหารแล้ว ภาษา R ก็ยังสามารถคิดเลขในรูปแบบอื่น ๆ อีก เช่น

2**5 # ยกกำลัง
[1] 32
9%%5 # หารเอาเศษ
[1] 4
10%/%3 # หารปัดเศษ
[1] 3

นอกจากการดำเนินการเหล่านี้แล้ว ภาษา R สามารถใช้ฟังก์ชันทางคณิตศาสตร์อื่น ๆ ได้อีกด้วย เช่น

cos(60) # ในหน่วย rad
[1] -0.952413
sqrt(9) # square root
[1] 3
exp(4) # e^4
[1] 54.59815

ชนิดของข้อมูล (Data Types)

โดยทั่วไปแล้ว ชนิดของข้อมูล ไม่ว่าเราจะเขียนโปรแกรมด้วยภาษาใดก็ตาม ชนิดของข้อมูลจะประกอบไปด้วย 3 ส่วน หลัก ๆ คือ

  • String (Character)
  • Integer (Number)
  • Boolean (Logical)
String

String คือ เหมือนกับเราเก็บข้อมูลเป็น Text เช่น พรี่โต, รถไฟ, 83120 (รหัสไปรษณีย์) ถ้าเห็นตัวเลขก็ไม่ต้อง งง เพราะ string ที่เป็นตัวเลขจะไม่สามารถนำมาทำ math operation ได้จ้า

ตัวอย่างการประกาศตัวแปร string

var1 <- "Heisenberg" # ประกาศตัวแปร var 1
var1 # พิมพ์ชื่อตัวแปรเพื่อให้แสดงผลค่าตัวแปร เหมือน printf
[1] "Heisenberg"
Integer

Integer คือตัวเลขนั่นแหละ ที่สามารถมาคิดคำนวณได้ ไม่ได้เก็บเป็นค่าคงที่แบบ string เช่น \(2.2e^{-7}\ (2.2 \times 10^{-7})\), 4, -9 ประมาณนี้

ตัวอย่างการประกาศตัวแปร int และการคำนวณเบื้องต้น

num1 <- 67 # ประกาศตัวแปร num1 เก็บค่า 67
num2 <- 9 # ประกาศตัวแปร num2 เก็บค่า 9
num3 <- abs(num2 - num1) # ประกาศตัวแปร num3 เก็บค่าสัมบูรณ์ของ num2 - num1
num3 # แสดงผลค่าตัวแปร num3
[1] 58
Boolean

Boolean คือ ข้อมูลแบบตรรกะ มีค่าได้ 2 ค่า คือ True (1) และ False (0)

ตัวอย่างการประกาศตัวแปร boolean และการคำนวณเบื้องต้น

sleep <- FALSE
sleep
[1] FALSE
sleep + 1
[1] 1

จะเห็นได้ว่า เมื่อคำนวณแล้วจะได้ค่าเท่ากับ 1 เพราะว่าค่า False มีค่าปกติ การทางคณิตศาสตร์ได้เป็น 0 นั่นเอง

การแปลงค่า

ดังที่ได้เห็นไปข้างต้นว่า ข้อมูลชนิด string หรือ character นั้น ไม่สามารถนำมาดำเนินการทางคณิตศาสตร์ได้ แล้วถ้าเราต้องการคำนวณล่ะ จะทำอย่างไร

วิธีนั้นคือ การแปลงค่านั้นเอง ลองดูในตัวอย่างแล้วทำความเข้าใจ

post_num <- "90110" # ประกาศตัวแปรชนิด string มีค่า 90110
postInt <- as.numeric(post_num) # ประกาศตัวแปรใหม่ ที่ค่าเป็น post_num ที่แปลงเป็น int แล้ว
postInt + 200 
[1] 90310

แค่นี้เอง เท่านี้ก็สามารถให้ string คิดเลขได้แล้ว นอกจาก as.numeric() แล้ว ยังมีฟังก์ชันแปลงอื่น ๆ อีก เช่น as.character() และ as.logical()

data.table

ในเมื่อเราเข้าใจ concept หลัก ๆ แล้ว ที่เหลือมาทำความเข้าใจในหัวข้อนี้ดีกว่า เพราะมันคือหัวใจสำคัญของเนื้อหานี้ คือ การใช้ library ชื่อ data.table ในการคำนวณสถิติ

ในการที่เราจะใช้ library นี้ ก่อนอื่นเราต้อง load มันขึ้นมาก่อน

library(data.table) # ต้อง load ทุกครั้งก่อนใช้

ต่อมา การที่เราจะคำนวณข้อมูลทางสถิติได้ เราจะต้องนำเข้า dataset ที่เราจะใช้ โดยตัวอย่างต่อไปนี้จะใช้ dataset สุดคลาสสิกอย่าง ดอก Iris เพื่อสร้างความเข้าใจ ก่อนที่จะไปเริ่มในเนื้อหาที่วิเคราะห์เรื่องระบาดวิทยาต่อไป

จริง ๆ แล้ว iris มันมีใน R อยู่แล้ว แต่ช่างมันเถอะ

library(data.table) # ต้อง load ทุกครั้งก่อนใช้

สถิติทางระบาดวิทยา กับ data.table

เราจะมาเริ่มด้วยตัวอย่างที่อยู่ในช่วงต้น แต่ dataset นั้นจะมาจากการสังเคราะห์ของ ChatGPT เนื่องจากเราไม่มี dataset ที่อาจารย์ใช้

# Cr. Aj. Chanon
library(data.table)
dt <- fread('../../../misc/diabetes.csv')
result_01 <- dt[age >= 50, .(n_patients = .N, mean_hba1c = round(mean(hba1c), 2)), by = gender][order(gender)]
print(result_01)
   gender n_patients mean_hba1c
   <char>      <int>      <num>
1: Female          5       6.92
2:   Male          5       7.14

round(mean(hba1c), 2) คือ ปัดทศนิยมให้เหลือ 2 ตำแหน่ง

n_patients = .N คือ ดู row ของผู้ป่วยที่เข้าเกณฑ์ตาม i

Hypothesis testing 💀

หัวข้อนี้แหละ ที่เราจะได้นำสิ่งที่เราเรียนมาทั้งหลาย มาปรับใช้

โจทย์ 1 ใช้ dataset เดิม

ต้องการทราบผลเปรียบเทียบความแตกต่างของค่า HbA1c ระหว่างเพศ

ใช้หลัก VSGIA เพื่อเลือกการทดสอบสมมติฐาน

V : ดูตัวแปร ว่ามีตัวแปรอะไรบ้าง ในที่นี้คือ HbA1c กับ เพศ

S : เราต้องดู Scale of measurement ก่อนว่า มันคือ Scale อะไร เหมือนเพศ คือ Nominal scale และ ค่า HbA1c เป็น Ratio scale

G : ดูกลุ่มตัวอย่างว่ามีกี่กลุ่ม ในที่นี้ เราดูที่เพศ จึงมี 2 กลุ่ม

I : ดูความเป็นอิสระ ในที่นี้ เป็นอิสระ

แต่ก่อนจะไปถึง A เราต้องวัด Normal distribution ก่อน เพื่อดูว่าเราควรใช้การทดสอบสถิติรูปแบบไหน

# Shapiro-Wilk
dt[, shapiro.test(hba1c), by = gender]
   gender statistic   p.value                      method data.name
   <char>     <num>     <num>                      <char>    <char>
1: Female 0.9385501 0.6557061 Shapiro-Wilk normality test     hba1c
2:   Male 0.9523515 0.7539730 Shapiro-Wilk normality test     hba1c

ดูจาก Shapiro-Wilk ก็น่าจะไม่เป็น Normal distribution แหละ (p < 0.05) ขี้เกียจทำอันอื่นละ ทำไม่เป็น

สรุปได้ว่า A ที่ใช้คือ Wilcoxon rank sum test หรือในอีกชื่อคือ Mann-Whitney U test

# Wilcoxon rank sum
wilcox.test(hba1c ~ gender, data = dt, exact = FALSE)
